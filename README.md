# Skills

A collection of reusable agent skills for focused workflows: prototyping UI/UX
ideas, tightening prose, and simplifying changed code.

## Install

Install the collection:

```bash
npx skills add boojack/skills
```

Update an existing installation:

```bash
npx skills update boojack/skills
```

## Available skills

- **`ui-prototype`**: Turn UI/UX ideas into polished interactive prototypes
  delivered as one verified, self-contained HTML file.

- **`tighten-writing`**: Restructure supplied prose or notes so their purpose,
  reasoning, and decisions are clear, direct, and precise without changing
  meaning or claim status.

- **`simplify`**: Review changed code for reuse, simplification, efficiency,
  and abstraction-level issues, then apply and verify behavior-preserving fixes.
